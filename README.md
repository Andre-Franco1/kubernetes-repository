# ☸️ Kubernetes Repository  

A collection of manifests, configuration files, and experiments created while studying a [kubernetes course](https://www.udemy.com/course/kubernetes-do-basico-ao-avancado/).  
This repository serves as a sandbox for learning, experimenting, and consolidating Kubernetes concepts.

---

## 📘 About  

The repo includes:  
- YAML manifests for Pods, Deployments, Services, and ConfigMaps  
- Experiments with Namespaces, ReplicaSets, and Secrets  
- Examples of Ingress, Volumes, and Persistent Volume Claims (PVCs)  
- Practical exercises covering real-world Kubernetes use cases
